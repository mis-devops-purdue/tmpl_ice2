# Contributing

## ICE 2: your bio
- Branch name: `bio/<your-purdue-username>`
- One file per person: `bios/<your-purdue-username>.md`. Don't edit anyone else's file, and leave `README.md` alone.
- Commit at least twice, push, and open a pull request. You don't review or merge: your instructor merges ready pull requests.

## Hands-On 2.2: your Team Directory line
- Pull the latest `main`, then create a branch named `readme/<your-purdue-username>`.
- Add **one line** to the Team Directory in `README.md`, in this exact format, linking to your own bio:
  `- [Your Name](bios/your-purdue-username.md)`
- Don't change or remove any other line. Push and open a pull request.
- If GitHub says your pull request has a conflict, that's expected: many people edit the same list. Leave it; your instructor's bot keeps everyone's line.

## Both
- Write commit messages in the imperative: "Add bio for Jane Doe", "Add Jane Doe to the Team Directory".
- Never change files under `.github/`.

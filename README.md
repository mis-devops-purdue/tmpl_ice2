# DevOps Bios

The team directory for MIS 58710. Every new team member adds a short bio through a pull request.

## How to contribute
1. Create a branch named `bio/<your-purdue-username>`.
2. Copy `bios/_TEMPLATE.md` to `bios/<your-purdue-username>.md` and fill it in.
3. Commit at least twice, push your branch, and open a pull request into `main`.
4. Leave this `README.md` alone for now. Your instructor will tell you when to add your link to the Team Directory below (Hands-On 2.2).

You don't review, approve, or merge anything in ICE 2: your instructor merges the pull requests that are ready.
`main` is protected, so nobody pushes to it directly.

A bot posts a checklist on your pull request and updates it as you go.
